# Игротека

11 браузерных игр в одном месте: общее меню выбора игры, аккаунты (регистрация и вход), облачные сохранения и рейтинг игроков.

| Игра | Жанр | Файл |
|---|---|---|
| Царства | 3D-эволюция: клетка → животное, растение, гриб или колония | `games/tsarstva.html` |
| Исток | 3D-эволюция организма на острове | `games/istok.html` |
| Нить | 3D-лабиринт, 60 уровней | `games/nit.html` |
| Искры | экшен-головоломка, 120 уровней | `games/iskry.html` |
| Рубежи | стратегия захвата территории, 40 уровней | `games/rubezhi.html` |
| Карусель | головоломка с конвейером, 60 уровней | `games/karusel.html` |
| Валики | головоломка с покраской, 100 уровней | `games/valiki.html` |
| Полки | сортировка предметов, 60 уровней | `games/polki.html` |
| Такт | ритм-головоломка, 60 уровней | `games/takt.html` |
| Мозаика | мозаичный разбор, 264 картины | `games/razbor.html` |
| Восемь залов | игровой тест на IQ | `games/zaly.html` |

## Запуск на сервере

Нужен только Python 3.8 или новее, ничего ставить не надо. Репозиторий публичный, ключ доступа не нужен. Команды по одной строке:

```
git clone https://github.com/mazohist-1/Games.git
```
```
cd Games
```
```
python3 server.py 8000
```

Сайт откроется на `http://АДРЕС_СЕРВЕРА:8000`. Порт можно поменять: `python3 server.py 8080`.

`server.py` заменяет `python3 -m http.server`: он так же раздаёт файлы и вдобавок обслуживает аккаунты.

Чтобы сервер работал после закрытия терминала:

```
nohup python3 server.py 8000 > server.log 2>&1 &
```

Остановить его:

```
pkill -f "server.py"
```

Обновить игры с GitHub (потом перезапусти сервер):

```
git pull
```

## Запуск в Docker

Команды по одной строке, из папки Games:

```
docker compose up -d --build
```

Сайт откроется на `http://АДРЕС_СЕРВЕРА:8000`. Аккаунты и сохранения лежат в томе `games-data` и не пропадают при пересборке. Контейнер сам поднимается после перезагрузки сервера.

Обновить игры:

```
git pull
```
```
docker compose up -d --build
```

Посмотреть журнал: `docker compose logs -f`. Остановить: `docker compose down`.

Если `docker compose` не найден, то же без compose:

```
docker build -t games .
```
```
docker run -d --name games --restart unless-stopped -p 8000:8000 -v games-data:/data games
```

## Аккаунты и сохранения

- Регистрация и вход — кнопка «Войти» в правом верхнем углу меню.
- Без аккаунта прогресс хранится только в браузере. С аккаунтом он сохраняется на сервере и подтягивается на любом устройстве.
- При регистрации прогресс, уже набранный в этом браузере, переносится в новый аккаунт.
- При входе в существующий аккаунт в браузер загружается прогресс из аккаунта.
- В профиле: прогресс по каждой игре, смена имени и пароля, выход и удаление аккаунта.
- Рейтинг: очки = все звёзды + 3 за картину в «Мозаике» + 15 за вершину эволюции в «Истоке» и «Царствах».
- Внутри каждой игры слева есть маленькая кнопка с домиком — возврат в меню (её можно перетащить). Зелёная точка на ней значит, что прогресс сохраняется на сервере.

Все данные лежат в одном файле `data/games.db` (SQLite). Пароли хранятся в виде хэша PBKDF2. Резервная копия:

```
cp data/games.db games-backup.db
```

Папка `data/` не попадает в git.

## Без сервера

Если открыть сайт через `python3 -m http.server` или GitHub Pages, меню и все игры работают, но без аккаунтов: прогресс хранится только в браузере.

Three.js для 3D-игр и шрифты подгружаются из интернета.
